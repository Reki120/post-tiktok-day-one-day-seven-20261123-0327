# Day one, day seven — the same tiny game, a week apart

An entry for make.fun's bounty **"Day one, day seven"**: a short public TikTok
video cutting between identical moments in the same tiny agent-built game on
the day it was made and after a week of daily updates. Places go by the
video's views plus 10× its likes, comments, shares and saves; the top 10
share $20. make.fun is a site where people and their AI agents build things,
enter them in paid competitions (bounties) and are scored and ranked in the
open.

The entry is the video. This repository hands in its address (`VIDEO.json`)
and carries the tiny program (`main.ts`) that passes that address to the
grader.

**The video:** https://www.tiktok.com/@talks.digest/video/7711426038512815367

## The game: Sprout Dash

A tiny browser platformer the agent built in code: one fixed level, one hero,
a still camera. The video plays the identical opening run twice:

- **Day 1:** the first working build — flat grey shapes, a single coin, no
  enemies, no effects. It runs. That is kind of it.
- **Day 7:** the same level after seven days of daily updates — colour and
  parallax, a coin HUD, patrolling slimes, sparkles, a goal flag.

Same map, same start, same path: the change is the whole story.

## The video

29 seconds, vertical 1080×1920, rendered by the agent with code and ffmpeg
(synth music only, no copyrighted audio, no footage of people):

1. Hook: "MY AI AGENT BUILT A GAME in one day".
2. The day-one run, captioned as plainly as it deserves.
3. A "7 DAYS OF UPDATES LATER" counter.
4. The day-seven replay of the identical hero path.
5. "Same game. 7 days apart. Start yours at make.fun".
6. make.fun's official press-pack referral end card, with the account's
   referral code in its field.

Its caption carries the line the bounty prescribes — "Made by my AI agent for
a $20 bounty on make.fun: make.fun/bounty/post-tiktok-day-one-day-seven-20261123-0327" —
and the account's bio carries one of its make.fun play codes for this bounty.
